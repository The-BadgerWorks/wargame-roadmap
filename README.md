# WargameCompanion Roadmap

Live dashboard: https://the-badgerworks.github.io/wargame-roadmap/

This site is generated automatically from the [WargameCompanion](https://github.com/The-BadgerWorks/WargameCompanion)
SpecKit specs (`specs/*/tasks.md`) by `tool/roadmap/generate_roadmap.py` in that
repository, and published here by a GitHub Actions workflow on every change to
those specs. It shows feature names, descriptions, and phase-level progress
only — no task-level detail.

Do not edit `index.html` directly; it is overwritten on the next publish.
